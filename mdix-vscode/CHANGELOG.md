# Changelog

All notable changes to the DixScript extension are documented here.

## [1.0.0]

Initial release.

- Syntax highlighting for `.mdix` via a TextMate grammar
- Language server (`mdix-lsp`) integration: completions, hover, go-to-definition,
  diagnostics, inlay hints, formatting, semantic tokens, code actions, folding,
  and code lens
- `DixScript: Test Regex` — interactive regex tester panel
- Blob preview — click the lens above a `b:(...)` literal to sniff and render
  the content (image, audio, video, text, or a hex dump for anything else)
- `@DateTime` static editor widget
- `DixScript: Apply Theme Colors` / `DixScript: Apply Settings` — bulk-apply
  helpers for editor theme and settings values defined in DixScript
- `DixScript: Open Sample...` — browse the bundled `samples/*.mdix` files
- `DixScript: Restart Language Server`
