# Support

## Reporting a bug

Open an issue on the [DixScript-Rust repo](https://github.com/Mid-D-Man/DixScript-Rust/issues).
Include:

- Your OS and VS Code version
- The extension version (`Extensions` view → DixScript → gear icon → "Copy")
- Steps to reproduce, and a minimal `.mdix` snippet if the issue is
  language-server related

For language-server issues, set `dixscript.server.trace` to `"verbose"`,
reproduce the problem, and attach the output from the
**DixScript LSP Trace** output channel (`View` → `Output` → select
"DixScript LSP Trace" from the dropdown).

## Asking a question / requesting a feature

Open a [discussion or issue](https://github.com/Mid-D-Man/DixScript-Rust/issues)
on the same repo.

## Getting started

Run **DixScript: Open Sample...** from the Command Palette to browse the
bundled example `.mdix` files.
